When to use a project

A project is a workspace with its own chats, files and instructions. Without one, every chat starts from scratch; with one, Claude already knows the account and how you like things done.

  • Context — upload reference files once (an SOV, guidelines, a template) and every chat in the project can use them.
  • Instructions — tell Claude how to work in this project (tone, format, what to always check).
  • Memory — Claude remembers what it learns in this project’s chats. It doesn’t carry over to other projects.

Use one for:

  • Ongoing work for one account — all its chats, SOVs and docs in one place.
  • A multi-step job — like training docs, where several chats feed one result.
