Permissions

Before Claude does something that touches your files, tools, or the browser, it checks in and asks permission — so you always control how much access it has. Each prompt gives you three choices.

  • Always allow — Claude stops asking for that kind of action and just does it from now on. Best for the repetitive, trusted steps you do constantly — like carrier submissions, where a skill fills the same portal over and over. Choosing this once saves you from clicking “allow” on every single step.
  • This time only — Claude does it just this once, then asks again next time. Best when you want to keep a closer eye — for example, writing to or changing a specific file, or anything you don't do routinely. You approve each instance as it comes up.
  • Deny — Claude doesn't do it. Use this if it's about to do something you don't want, then tell it what to do instead.
Rule of thumbThe more routine and trusted the action, the more comfortable you can be with Always allow. The more sensitive or one-off it is — changing files, or anything outside the task — the more it's worth This time only so you see each one. When in doubt, pick This time only.
When Claude asks to…Usually pick
Run a carrier submission (fill the portal, move through the site)Always allow — you run these constantly
Read files in a folder you've shared for the taskAlways allow, or This time only
Write to or overwrite a specific fileThis time only — so you see each change
Delete something, or act outside the current taskThis time only, or Deny if it isn't what you want
In the browser, it's worded differentlyWhen a skill works in Chrome, the same idea appears as “All for this website” (like Always allow) versus “Allow for this website” (this time only). For carrier work, pick All for this website so Claude isn't stopped at every step — see Claude in Chrome.
Permission vs. accessPermissions decide what Claude may do. What it can reach in the first place is a separate thing — Claude only sees the files and folders you've shared with it (see Uploading folders).
