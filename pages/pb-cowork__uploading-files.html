Uploading files

Attach files instead of copy-pasting — Claude reads the real document. Click + → Add files or photos, or drag a file into the chat.

Works with: PDF, Excel (SOVs, loss runs), Word, PowerPoint, .vtt transcripts, and images. Most carrier skills need the SOV — the Org Skills Directory lists what each one needs.

Lots of files?There’s a limit per message, so attach them in batches and say “don’t do anything yet, I’m still uploading more.” Give the go-ahead once everything is in.
