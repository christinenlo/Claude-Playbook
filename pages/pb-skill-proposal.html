Org Skill · New Business Proposal

Builds the formalized LaBarre/Oksnee new-business proposal for a condo association from the carrier quotes — and can fold in a comparison sheet, combining everything into one client-ready PDF.

Condos only for now. It fills the condo new-business tab (NB - CONDO) and isn’t built for PUDs yet. If a PUD is selected it stops rather than filling the wrong tab; PUD support is on the way.

Have these readyTwo files: the Proposal workbook template (the Proposal RNWL NB <date>.xlsx with the carrier dropdowns and LO logo — it can’t be rebuilt from scratch, so you have to provide it) and the carrier quotes (PDF) — the package quote plus any ancillary quotes (Crime, D&O, Umbrella, Workers’ Comp).

It runs in three parts — you can stop after the proposal, or go all the way to a combined PDF:

  1. Proposal. In Cowork (on Sonnet), type /lo-build-formalizedcomparison-proposal, attach the template and the quotes, and send. Claude asks a few things it can’t safely guess first — which quote option to use, any broker or risk-management fee, and your preparer details — then fills the NB - CONDO tab and returns the finished Proposal workbook (.xlsx).
    Expect it to check in — that’s on purposeThis proposal is a document a licensed broker signs and a board relies on, so Claude confirms the scope and every value before it writes, rather than guessing — a wrong number is costly. If it pauses to ask, that’s working as intended. And as always, give the finished proposal a once-over against the quotes before it goes to a board or client.
  2. Comparison. Send the competing carrier quotes (or the expiring policy) and ask to add a comparison. Under the hood, Claude uses the Comparison Sheet skill to build a one-page sheet — with your formalized option as the LaBarre/Oksnee recommendation.

    Try something like: “Here is the edited and revised final version of the formalized proposal — this will be the recommended option when we build the comparison. Here is the second option; leave all lines the same (including GL) and create option 2 with this property quote.”

  3. Combine. Claude merges the two PDFs into one — the comparison dropping in right after the intro page. You end up with a client-ready PDF: cover letter, comparison, coverage summary, and the premium & signature page.

    Try something like: “Here are your final docs — continue to combine and make the final proposal.”

Before you combine: PDF to PDFTwo things make the merge come out clean. First, export the finished workbook to a PDF yourself (Excel’s own “Save as PDF”) and hand Claude that — so it’s PDF + PDF, not a re-converted file that re-wraps your cover letter. Second, check the proposal looks right as a PDF first — tweak cell heights, margins and the print area so nothing’s clipped. Get it as final as you can before combining; you can always send it back to Claude for more edits, but finalizing first saves time.
