📊 Claude in Excel & Office

Claude can work right inside Excel, Word, PowerPoint, and Outlook — and hand you finished files.

The Microsoft connectors (SharePoint, Teams, Outlook) only read. Separately, Claude has add-ins that plug into the Office apps and can read and edit right inside them — handy for SOVs, comparison sheets, and HO-6s.

Claude for Excel

Install it once from Microsoft AppSource (search “Claude for Excel,” click Get it now), then sign in with your Claude account. It runs in Excel for Windows and Excel on the web (not the old 2016/2019 versions). Inside a workbook it can:

  • Answer questions about your data with the exact cells it used, so you can check its work.
  • Change an assumption and keep your formulas intact, fill an existing template, or work across multiple tabs.
  • Fix errors like #REF! and #DIV/0!, and do the usual sort / filter / pivots / formatting.

It warns you before overwriting existing data. It can’t run macros/VBA. Your enabled skills work inside the add-in too.

⚠️ Only use it on spreadsheets you trustAn outside file can hide instructions that try to redirect Claude — work on a trusted copy and review any change it flags. See Working safely with client data.

Across Word, PowerPoint & Outlook

With the add-ins installed, one conversation can move between apps — pull numbers from Excel into a Word memo or a PowerPoint deck, or figures from an Outlook thread into Excel. It only works on files you have open. (Toggle “Let Claude work across files” in each add-in’s Settings; it’s on by default.)

Claude can also hand you finished files

Even outside the add-ins, Claude can create real files you download — an Excel workbook, a Word doc, a PowerPoint, or a PDF — not just an on-screen answer. Just ask (“put this in an Excel file”). If it’s ever turned off, switch on Settings → Capabilities → “Code execution and file creation.” Files can be up to 30 MB, and this uses a bit more of your usage than a plain chat.
