Claude in Excel & Office

Work inside Excel, Word, PowerPoint and Outlook — or get finished files back.

The Microsoft connectors only read. The Office add-ins are different: they can read and edit right inside the app — handy for SOVs, comparison sheets and HO-6s.

Claude for Excel

Install once: in Microsoft AppSource search “Claude for Excel” → Get it now, then sign in. Works in Excel for Windows and on the web (not 2016/2019).

  • Answers questions about your data and shows the exact cells it used.
  • Changes assumptions without breaking your formulas, fills templates, works across tabs.
  • Fixes errors like #REF!, and sorts, filters, pivots and formats.
  • Warns before overwriting data. Can’t run macros/VBA. Your skills work in it too.
Only use it on spreadsheets you trustOutside files can hide instructions that try to redirect Claude. Work on a trusted copy — see Working safely with client data.

Across Word, PowerPoint & Outlook

With the add-ins installed, one conversation can move between open files — e.g. Excel numbers into a Word memo or PowerPoint deck. (“Let Claude work across files” is on by default in each add-in’s Settings.)

Getting finished files

Claude can also create files you download — Excel, Word, PowerPoint or PDF. Just ask: “put this in an Excel file.” Up to 30 MB. If it’s off, turn on Settings → Capabilities → Code execution and file creation.
