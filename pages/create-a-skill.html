How to create a skill

A skill is a reusable workflow you teach Claude once, then run any time by typing / and its name. If you keep walking Claude through the same multi-step task, turn it into a skill so you — and your teammates — never have to explain it again.

Recommended: Opus Building a skill is fiddly, and Opus is more thorough than Sonnet at getting the steps and details right — switch to it before you start.

Creating one isn’t coding. You just walk Claude through the task step by step, exactly like training a new hire — “step 1 is this, step 2 is that, this piece of info goes in this field.” When it works, tell Claude to save it, and it lands in your / menu for good.

The easiest way to start is the built-in /skill-creator. In a new chat, type /skill-creator and describe what you want — e.g. “I want a skill that fills the Arden form from an SOV.” It asks a few questions and builds the skill with you.

  1. Walk Claude through the task, step by step — “first click Quote type → Workers’ Comp, then pull the TIV from the SOV into this field…” Attach anything it should work from (an SOV, a template, a sample), or just describe it.
  2. Teach the “what-ifs.” If the task can branch, spell out both paths — “if there’s a policy number, do this; if not, do that.” Covering those forks is what makes a skill reliable.
  3. Build in a guardrail. Tell it to pause and ask you whenever it’s unsure — e.g. “if a value isn’t in the SOV, stop and ask me instead of guessing.”
  4. Save it. When it all works, say “the skill is done — please save it as a skill.” Give it a clear name and a one-line description — that description is how Claude knows when to reach for it.
  5. Test and tweak. Run it on a real (or sample) file. If something’s off, tell Claude what to change and re-save.

Other ways to make one

Turn an existing chat into a skill. Already worked through the task in a chat? Open its ▾ menu (or hover it in the left list → …) and pick Turn into skill — or just tell Claude, “turn this chat into a skill.” (See Renaming & quick actions.)

From a whole project. If you’ve built up a Project with several related chats, start a new chat inside that project and ask Claude to make a skill from all of them — e.g. “based on all these chats, make a skill that…” It draws on everything in the project.

Built something useful? To turn it into an org skill the whole team can run, ping @Christine Nguyen or @Joon Jung — we’ll go over it with you and upload it.

Building a browser skill? Open Chrome firstIf the skill works in the browser (a carrier submission, filling a form), have Chrome already open on your new Claude profile before you start. Claude connects to your open Chrome but can’t launch it itself.
Keep browser skills updatedIf a carrier changes their portal (a dropdown becomes a slider, a field moves), a browser skill can trip on that step — walk Claude through the changed part and re-save. If a shared org skill breaks, tell @Christine Nguyen.
