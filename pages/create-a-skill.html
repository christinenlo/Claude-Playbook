How to create a skill

If you keep walking Claude through the same multi-step task, save it as a skill — then anyone can run it with / and its name.

Recommended: Opus It’s more thorough than Sonnet at getting the steps right. No coding — you teach Claude like you’d train a new hire.

Easiest start: in a new chat, type /skill-creator and describe it — “I want a skill that fills the Arden form from an SOV.” It asks a few questions and builds it with you.

  1. Walk it through step by step — “click Quote type → Workers’ Comp, then put the TIV from the SOV here.” Attach any SOV, template or sample it should use.
  2. Cover the what-ifs — “if there’s a policy number, do this; if not, do that.” This is what makes it reliable.
  3. Add a guardrail — “if a value isn’t in the SOV, stop and ask me instead of guessing.”
  4. Save it — “the skill is done, please save it.” Give it a clear name and a one-line description (that’s how Claude knows when to use it).
  5. Test and tweak on a real or sample file, then re-save.

Other ways to make one

From a chat you’ve already done: its ▾ menu → Turn into skill, or just say “turn this chat into a skill.”

From a whole project: start a new chat inside the project and say “based on all these chats, make a skill that…”

Browser skills

  • Open Chrome on your Claude profile first — Claude can connect to it but can’t launch it.
  • If a carrier changes its portal, the skill can trip on that step. Walk Claude through the changed part and re-save.
