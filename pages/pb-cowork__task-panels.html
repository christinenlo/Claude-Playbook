Inside a Cowork task

While a task runs, the panels on the right let you follow along:

  • Progress — Claude’s checklist of steps, ticked off as it goes.
  • Working folders — the files and folders it’s reading from and saving to.
  • Claude in Chrome — only when the task uses the browser; shows which window it’s driving (see Claude in Chrome).
  • Context — the tools and files the task has used.
