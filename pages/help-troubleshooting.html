🔧 Troubleshooting

Who to contactFor anything that gets stuck — verification codes, error messages, a skill misbehaving, or questions not covered here — ping @Christine Nguyen.

Is Claude down?

Check status.claude.com. If there's an active outage, the issue is on Claude's side — wait for it to clear rather than reinstalling.

Common startup error messages

If you see any of these when opening Claude Desktop, capture a screenshot and ping @Christine Nguyen:

  • "Failed to start Claude's workspace. Can't reach the Claude API from Claude's workspace."
  • "VM service not running. The service failed to start."
  • "HCS operation failed: failed to create compute system…"
  • "API Error: Unable to connect to API (ECONNRESET)"
  • "Cannot create system 'cowork-vm' since Hyper-V is not installed"

Quick fixes to try first

  • Wrong results or odd behavior: confirm the model is Sonnet (model name, bottom-right of the chat).
  • An update is waiting: if you see Relaunch to update at the bottom-left, click it and give it a few minutes.
  • A skill won't run in the browser: make sure you're on your new Chrome profile, and set the site permission to "All for this website."
  • Claude paused waiting on you: if it asked you to log in, log in manually, then tell it "I'm logged in, please continue."
  • Claude is slow or seems stuck: Claude automatically compresses long chats to keep them running, and its sandbox can take a moment to restart — give it a minute. If it's still stuck, restart Claude (close it and reopen), then ask it to try again.
