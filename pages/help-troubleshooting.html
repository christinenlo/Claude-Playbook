🔧 Troubleshooting

Who to contactStuck on anything — a verification code, an error, a skill misbehaving? Ping @Christine Nguyen.

Is Claude down?

Check status.claude.com. If there’s an outage, wait it out — don’t reinstall.

Common startup error messages

See one of these when opening Claude Desktop? Screenshot it and ping @Christine Nguyen:

  • "Failed to start Claude's workspace. Can't reach the Claude API from Claude's workspace."
  • "VM service not running. The service failed to start."
  • "HCS operation failed: failed to create compute system…"
  • "API Error: Unable to connect to API (ECONNRESET)"
  • "Cannot create system 'cowork-vm' since Hyper-V is not installed"

Quick fixes to try first

ProblemTry this
Odd or wrong resultsCheck the model is Sonnet.
Using your limit fastCheck Effort isn’t on Max or Extra — High is the default.
Slow or stuckGive it a minute (it compresses long chats and restarts its workspace). Still stuck? Close and reopen Claude.
“Relaunch to update” showingClick it and wait a few minutes.
Browser skill won’t runUse your Claude Chrome profile and pick “All for this website.”
Claude is waiting on youLog in yourself, then say “I’m logged in, please continue.”
Scheduled task says “Permissions needed”Click Review. For routine tasks, set Permissions to Automatically approve (how).
Scheduled task didn’t runIf Require this computer is on, your computer must be awake — turn on Keep computer awake, or switch it off if the task only uses connectors.
Can’t reach files from web or phoneLocal folders and the browser only work while Claude Desktop is open (why).
Can’t edit an old tracker or artifactOnes made before August 19 can’t be edited — ask Claude to make it again (why).
A sharing option is greyed outCompany-wide projects and “Anyone with the link” are turned off for us — share with specific people (projects, artifacts).
