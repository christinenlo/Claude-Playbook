💡 Tips & Tricks

Practical tips from the team. Have one to add? Ping @Christine Nguyen.

Getting good results

  • Be specific. Not “fix this SOV” but “check the property values against the dec pages and flag anything that doesn’t match.” See How to prompt Claude.
  • Have it confirm the plan first — “summarize what you’ll do and wait for my OK.”
  • Attach the file, don’t paste it — Claude reads the real PDF or Excel more accurately.
  • Correct it in plain English — “use the 2025 premium, not 2024.” No need to start over.
  • Always review before it goes out — you’re the expert.

Saving time

  • Let it run in the background — Claude pings you when it needs you. Close the app if you like; Cowork keeps going in the cloud (except work on local files or the browser).
  • One project per association, so Claude remembers the account across chats. See Projects.
  • Pin what you use daily — chats and projects.
  • Start from a suggested scheduled task (Daily briefing, Inbox triage, Weekly review…) and set it to Automatically approve. See Scheduled tasks.
  • Uploading lots of files? Say “don’t start yet, I’m still uploading.” See Uploading files.
  • Dictate instead of typing with the microphone in the chat box.
  • Tidy your sidebar — right-click More → Edit sidebar… (how).

Useful features

  • Work inside Excel with the Claude for Excel add-in — it keeps your formulas and shows the cells it used.
  • Look things up — web answers come with citations, and Research does a deeper dig.
  • Make a Doc the team can edit — Artifacts → Make something new → Docs.
  • Use incognito for throwaway questions — not saved, but still visible to your admin. See Incognito mode.
  • New-business proposal? Get it right and save it as a PDF before combining it with a comparison. See New Business Proposal.

Usage & safety

  • Make your usage last — a new chat per account, reference files in a project, Sonnet for most work, Effort on High (never left on Max). See Token usage.
  • Stay updated — click “Relaunch to update” whenever it appears.
  • Lock down your Chrome profile — turn off password saving and autofill (how).
  • Client files: work on a trusted copy, use Manually approve, and don’t point Claude in Chrome at pages with client PII. See Working safely with client data.
  • Share client info only with people who need it — use Only people invited (how).
