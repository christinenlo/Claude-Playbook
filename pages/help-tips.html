💡 Tips & Tricks

A starter set of practical tips — add your own as the team finds what works. Ping @Christine Nguyen to get one added here.

  • Be specific. The more detail you give, the better the result. Instead of "fix this SOV," say "check the property values against the dec pages and flag anything that doesn't match."
  • Ask Claude to confirm the plan first. For anything important, say “summarize what you'll do and wait for my OK” before it starts — a quick verification step that catches misunderstandings early.
  • Attach the source, don't paste it. Drop in the actual PDF or Excel file with the + button rather than copying text — Claude reads the real document more accurately.
  • Keep related work in a Project. One project per association means Claude remembers the account across chats instead of you re-explaining it every time.
  • Let it run in the background. Once a skill starts, you can switch to other work — Claude pings you when it needs input or finishes. You don't have to watch it.
  • Correct it in plain English. If something's off, just tell Claude what to change ("use the 2025 premium, not 2024"). No need to start over.
  • Pin your go-to chats. Right-click → Pin the skills you use daily so they're always at the top.
  • Stay updated. Click "Relaunch to update" whenever it appears — newer versions are more accurate and match this guide's screens.
  • Keep an eye on your usage. Settings → Usage shows how much of your rolling ~5-hour session you've used and when it resets — handy to glance at mid-submission. See Token usage.
  • Make your usage last. Start a fresh chat for each account, keep reference files in a Project instead of re-uploading them, and save Opus for the genuinely hard stuff.
  • Always review before it goes out. Claude is fast, but you're the expert. Double-check anything headed to a carrier or client.
