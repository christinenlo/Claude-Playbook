Folder or no folder

Whether you add a folder decides where the project lives and whether you can share it.

With a folder → local (this computer only)

If you click Add folder, the project becomes local: it stays on your computer, won't sync or share, and Claude reads the files in that folder as context. Local projects show a Local badge and can't be shared afterward.

Without a folder → shareable

If you don't add a folder, the project lives in Claude and can be shared. Set its visibility to your organization (or keep it Private and invite specific people), and anyone you share it with can use the same project.

Which should I pick?Use a folder when the files live on your PC and you want to keep the project to yourself. Skip the folder when you want a shared team workspace.

What's shared, what's private

When you share a project, teammates get its setup — the instructions, knowledge, and context — so they can use the same project. But your chats and tasks stay private: everyone sees only their own. Inside a shared project you'll see the reminder “All chats are private unless shared.”

If you do want a colleague to see a particular conversation, share that individual chat — and remember it only shares the messages up to the moment you press Share. See Sharing chats & tasks.
