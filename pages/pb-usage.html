Token usage

Claude has usage limits, and it's worth knowing where you stand — especially mid-submission. You can check your usage anytime, and a few small habits make it stretch a lot further.

Check your usage

Click your name (bottom-left) → Settings → Usage. You'll see two bars:

  • Current session — your usage runs on a rolling ~5-hour window. The bar shows the percentage you've used and a countdown to when it resets (for example, “Resets in 1 hr 38 min”).
  • Weekly limits — a longer cap that refills each week, with its own reset day and time.
The 5-hour sessionMost everyday work never comes close to the limit. If you do run out, Claude simply pauses until the session resets — the Current session timer tells you exactly when. It's a rolling window, so it frees up on its own; you don't need to do anything.

Make your usage go further

A few habits keep you comfortably under the limit:

  • Start a fresh chat for each new task or account. Long chats get more “expensive” as they grow, because Claude re-reads the whole thread each time. New account → new chat.
  • Keep reference files in a Project. Files in a project's knowledge are reused without re-costing every time — so you're not re-uploading the same SOV in chat after chat. (See Projects.)
  • Batch your questions. Ask everything you need in one message rather than a dozen quick back-and-forths.
  • Be specific. Clear prompts mean fewer clarifying rounds — which means less usage. (See How to prompt Claude.)
  • Match the model to the job. Sonnet — or Haiku for quick jobs — handles almost everything; save Opus for genuinely complex reasoning, since heavier models use more. (See Which model to use.)
  • Keep the effort level moderate for everyday tasks — a higher effort does extra work (and uses more usage) that routine tasks don’t need.
