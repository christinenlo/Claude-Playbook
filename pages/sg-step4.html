4Harden Chrome Security

Do this inside your new profile. Open Settings from the three-dot menu (top-right).
  1. Enhanced protection: Privacy & Security → Security… …then select Enhanced protection.
  2. Block third-party cookies: Privacy & Security → Third-party cookies… …then choose Block third-party cookies.
  3. (Optional) Clear site data on close: Privacy & Security → Site settings… → scroll to Additional content settings… → On-device site data… → select Delete data when you close all windows (recommended for shared machines).

Workflow isolation

  • Profile A (Research): use your regular profile to search publicly available data.
  • Profile B (Submission): open your secure profile only when you're ready to log into a carrier portal.
  • Copy/paste tip: copy what you need from Profile A into the AI tool in Profile B, so Claude only sees the data you give it — not your whole browsing history.
