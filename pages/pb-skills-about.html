When to use skills

Skills are prebuilt workflows your team made. Type / in Cowork to run one: it opens the right portal or tool, fills it from your files, and pings you when it needs you. You always review before anything is submitted.

  • Most need your SOV (Excel) — the directory’s Files needed column says what each takes.
  • The Creator column shows who to ask about each one.

Which skill do I use?

Find the carrier or task in the Org Skills Directory. The most common:

For…Type
An Arden submission/lo-arden-submission
An ACORD in Epic/lo-create-acord
A comparison sheet/lo-insurance-comparison-sheet

Getting too many check-ins?

Add it right after the skill name: “only check in when you’re done” or “don’t stop unless you’re truly stuck.” Skills still pause when they’re unsure — on purpose, so you get the final say.

If Claude gets something wrong

Don’t submit or send it. Fix the field yourself, or tell Claude what’s off — “the year built should be 1998, not 1988.”

If a skill keeps making the same mistake, screenshot it and ping @Christine Nguyen so it can be fixed for everyone.
