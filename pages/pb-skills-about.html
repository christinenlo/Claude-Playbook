When to use skills

Skills are prebuilt workflows your team created — type / in Cowork to run one. Each opens the right portal or tool, fills it from your files, and pings you when it needs input or finishes. You always review before anything is submitted.

  • They save you from doing the same multi-step task by hand every time.
  • Most take your SOV (Excel) as the input — check the Files needed column in the directory.
  • Anyone can build one; the Creator column shows who to ask about each.
Which skill do I use?Match the carrier or task in the Org Skills Directory — e.g. Arden → /lo-arden-submission, an ACORD in Epic → /lo-create-acord, a comparison sheet → /lo-insurance-comparison-sheet. Not sure? Ping the skill's creator.
Getting too many check-ins?If a skill stops to ask you more than you'd like, tell it up front — right after you type the skill, add something like “only check in with me when you're done” or “don't stop to ask unless you're truly stuck.” Just know the skills are built to pause and ask when they're unsure — that human-in-the-loop check is a guardrail on purpose, so you always get the final say before anything important goes out.
If Claude gets something wrongDon't submit or send it. You can fix the field yourself, or tell Claude exactly what's off (e.g. “the year built should be 1998, not 1988 — please correct it”) and it'll redo it. If a skill keeps making the same mistake, screenshot it and ping @Christine Nguyen so it can be fixed for everyone.
