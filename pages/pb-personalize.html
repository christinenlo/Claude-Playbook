Personalize Cowork

Optional tweaks: set your instructions, turn on memory, and check your connectors.

Settings

Click your name (bottom-left) → Settings.

SectionWhat it’s for
GeneralAppearance, Voice (how Claude talks back), and Notifications — get pinged when a long task finishes.
AccountYour profile and where you’re signed in — sign out any session you don’t recognize.
UsageHow much of your limit you’ve used — see Token usage.
CapabilitiesFeature switches, like file creation.
MemoryWhat Claude remembers about you — see Memory.
Desktop appSystem — run on startup, keyboard shortcuts, and Keep computer awake for scheduled tasks. Extensions — apps and files on your PC.
CustomizeSkills (see the Org Skills Directory) and Connectors for web tools like Microsoft 365. The Claude Chrome extension is a connector too.

You can ignore Claude Code, Design systems, Developer and Plugins — they’re for developers.

Instructions for Claude optional

Tell Claude once how you like it to work, and it applies that to every chat and Cowork task. In Settings, fill in Instructions for Claude and click Save changes. Edit or clear it anytime.

Examples:

  • “Keep answers short — bullets over paragraphs, and lead with the answer.”
  • “I work in HOA/condo insurance — use SOV, ACORD, COI and master policy without explaining them.”
  • “Before filling any carrier form, show me the values and wait for my go-ahead.”
  • “Only search the web when I ask.”

Memory optional

With memory on, Claude remembers your role, the accounts and carriers you work with, and how you like things done — in both chat and Cowork — so you don’t re-explain yourself. It’s off until you turn it on.

Turn it on: Settings → Memory → switch on Generate memory from chats. (Search and reference chats also lets Claude look back through your past chats.)

See or change what it knows: Claude saves things as you chat, sorted into your Profile, Topics and Areas. Click one to read, edit or delete it — or type a correction in the box at the bottom, e.g. “I mostly handle condo renewals.” Sensitive subjects like health aren’t saved unless you turn that on.

Used another AI tool before? Click Start import, copy the prompt into that tool (for example Microsoft Copilot), then paste its answer back and click Add to memory.

Keep it work-appropriateNo passwords, birthdays, financial or health details.

Connectors

Go to Settings → Customize → Connectors and check these three show a checkmark. If one doesn’t, click Connect.

  • Microsoft 365
  • Microsoft Learn
  • Claude in Chrome

What the Microsoft connectors can do: read your Outlook, SharePoint and Teams — and, for the actions your admin has switched on, act for you: draft and send email, organize mail and your calendar, create and update SharePoint files, and post in Teams. Claude follows your approval settings before acting, and it can’t send attachments.

Quick test — if these come back with the right info, you’re connected:

Summarize my 3 most recent Outlook emails.Checks Outlook.
Find the SOV for Sample Ridge HOA in our SharePoint and show me the total insured value.Checks SharePoint.
What was posted in our renewals Teams channel this week?Checks Teams.
