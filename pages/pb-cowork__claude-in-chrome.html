Claude in Chrome

When a task needs the browser — a carrier portal, Epic, a browser skill — Claude uses Claude in Chrome, and only once you allow it (see Permissions).

Before a browser skill: open Chrome on your Claude profileIt needs the Claude Chrome extension, installed and logged in (Step 2). If Claude says it can’t connect to the browser, open Chrome on the Claude profile and tell it to try again.

Each skill opens its own labeled tab (e.g. “Epic,” “Arden”), so tasks running side by side are easy to tell apart.

Claude can only use tabs in its Claude tab group. You control what’s in it:

  1. Let Claude use a tab — right-click it → Add tab to group → Claude. (Or drag the tab onto the group.)
  2. Take it back — right-click → Remove from group, or drag it out.
  3. It’s saved for next time on your bookmarks bar as “Claude.”
  4. Clean up — right-click it on the bookmarks bar to open, unpin, or delete the group.
Fewer interruptionsWhen Claude asks for browser permission, pick “All for this website” from the dropdown so it doesn’t ask at every step.
