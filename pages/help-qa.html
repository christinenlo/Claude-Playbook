❓ Q&A

A running list — we'll keep adding as questions come up.

Setup & login

Which Chrome profile should I be in?

Your new "Claude Profile" (the one with the distinct color) for anything involving Claude or carrier portals. Keep your everyday browsing in your personal profile.

Do I sign the new profile into Google?

No — choose Stay signed out when creating it. Don't save passwords to it either.

What do I log in with?

Use your own account in both the Chrome extension and Claude Desktop, unless you've been assigned to Athena. If you need a verification code, ping @Christine Nguyen.

Chrome or Edge?

Chrome only. This setup doesn't run on Edge.

Which model and settings should I use?

Sonnet for everyday work, with Extended Thinking OFF. Set it via the model name at the bottom-right of the chat. (See Claude Models for when to use Opus or Haiku.)

Everyday use

Does Claude need internet? Will it keep working if my Wi-Fi drops?

Yes — Claude needs an internet connection. The AI itself runs on Anthropic's servers (not on your computer), so it can't work offline. If your connection drops in the middle of something, Claude just pauses — once you're back online, tell it “please continue” and it picks up where it left off.

Can I pause and come back to a task later?

Yes. If Claude is waiting on you (say, to log in), it simply waits — nothing times out. And your chats are always saved, so if you step away or even close Claude, you can reopen the conversation from Recents in the sidebar and tell Claude “please continue” to pick back up.

Do I have to keep Claude open while it's working?

For a task running on your computer, yes — keep the Claude window open and your computer awake, since the work happens on your machine. You can minimize it or switch apps; just don't fully close it. Or run it in the cloud and it keeps going even after you close the app — though tasks that need your local files or the browser still need the desktop app open. (Scheduled tasks on your computer are the same — they only run while Claude is open and awake; cloud ones don’t need it.)

Can Claude make mistakes?

Yes — Claude is fast and usually accurate, but it isn't perfect, so you're still the expert. Always review anything headed to a carrier or client before it goes out, and if something's off, just tell Claude what to fix in plain English. See If Claude gets something wrong.

Should I use the Fable model?

No — skip Fable for our work. It’s much slower than Opus and uses far more of your usage, with no upside. Stick with Sonnet (or Opus for hard tasks and building skills). See Which model to use.

Can I use Claude on my phone, or keep a task going after I close the app?

Yes — Claude Cowork also works on the web (claude.ai) and on mobile, and you can set a task to run in the cloud so it keeps going after you close the app. Just note that anything needing your local files or the browser (SOVs, ACORDs, portal submissions) still needs the Claude Desktop app open on your computer. See Claude in the cloud.

I need to attach a lot of files at once — what if I hit the limit?

Cowork caps how many files you can attach to one message. Keep adding them in batches, and tell Claude “don’t do anything yet, I’m still uploading more” so it waits until you’re done — then give it the go-ahead. See Uploading files.

Security & passwords

Why a separate Chrome profile?

It isolates your secure work from everyday browsing. Since profiles are separate browser instances, a problem in one can't reach an active portal session in the other.

Why never save passwords in the new profile?

For security, the secure profile stays credential-free. Copy a password over from your personal profile's Google Password Manager only when you need it, and click Never if asked to save.

What are the recommended security settings?

Enhanced protection on, block third-party cookies, and optionally delete site data when all windows close. Full steps in Step 4.

Do I need to turn off autofill in my Chrome profile?

Yes — it’s a required first step. In your new profile, open Password Manager → Settings and turn off Offer to save passwords, Automatically create a passkey, and Sign in automatically so the profile never saves or auto-fills credentials. Step-by-step in Turn off autofill.

How do I keep a chat private, or stop it from being saved?

Start an incognito chat — click the ghost icon (top-right) or press Ctrl+Shift+I. It won’t be saved to your history or memory. Two caveats: nothing is recoverable once you close it (don’t use it for work you need to keep), and it’s still visible to your admin — it’s not a way to hide work from the company. See Incognito mode.

Running skills

How do I start a skill?

In Claude Desktop, type / to open the skill menu and pick the one you want. See the Org Skills Directory for the full list.

What file does a skill need?

Most carrier skills need the SOV (Excel). The Org Skills Directory lists exactly what each one requires. Attach it with + → Add files or photos.

Does Claude log into the carrier site for me?

No — always log in manually. Never save passwords or give Claude your credentials. After you're in, tell it "I'm logged in, please continue."

Claude keeps asking for browser permission.

Use the dropdown on the permission prompt and pick "All for this website" so it can keep working on that site without asking each time.

Can I do other things while a skill runs?

Yes. Skills run in the background, each in its own labeled Chrome tab, and Claude pings you when it needs input or finishes. You can run more than one at a time.

How do I make my own skill?

Walk Claude through the task step by step (like training a new hire), or start with /skill-creator and describe what you want — then tell it to save the skill. Use Opus for this. Full steps in How to create a skill.

Can I turn a chat I’ve already done into a skill?

Yes — open the chat’s ▾ menu and pick Turn into skill, or just tell Claude “turn this chat into a skill.” You can also build one from all the chats in a project. See How to create a skill.

How do I get my skill added as an org skill for everyone?

Ping @Christine Nguyen or @Joon Jung — we’ll go over it with you and upload it to the Org Skills Directory.

What’s the Email Tracker?

A skill (/lo-email-tracker-artifact) that builds a live view of your Outlook mailbox — what’s come in, sent emails still awaiting a reply, and flagged items — with one-click draft replies. It needs Microsoft 365 connected. See Email Tracker.

Sharing, projects & usage

Can I share a chat with a coworker?

Yes — open the chat, click Share (top-right), choose Shared, and create the link. It only shares messages up to the moment you press Share, and attached files aren't included. Cowork tasks can't be shared — only chats. More in Sharing chats & tasks.

If I share a project, can people see my chats in it?

No. Sharing a project shares its setup (instructions, knowledge, context), but chats and tasks stay private — everyone sees only their own. Share an individual chat if you want someone to see it. See Shared vs private.

What's the difference between a local and a shareable project?

If you add a folder, the project is local — it lives on your computer only and can't be shared. If you don't add a folder, it can be shared with your organization. See Folder or no folder.

How do I rename a chat or task?

Click the ▾ next to its title and pick Rename — or hover it in the left list, click …, and choose Rename. See Renaming & quick actions.

How do I check my usage, and what is the 5-hour limit?

Click your name (bottom-left) → Settings → Usage. Your Current session runs on a rolling ~5-hour window that resets on its own; there is also a weekly limit. Everyday work rarely gets close. See Token usage.

Is the information I share with Claude private?

Claude only sees the files and folders you actually share with it — it has no access to the rest of your computer. Your chats and Cowork tasks stay private to you unless you deliberately share a chat, and the Microsoft connectors (SharePoint, Teams, Outlook) are read-only. As a rule, don't paste passwords or sensitive personal details into a chat.

How do I pin a project to the sidebar?

Open the project and click the pin icon at the top-right (“Pin project”), or use a project’s ⋮ menu on the All Projects page or in the sidebar. Pinned projects sit under Pinned for one-click access. See Pin your projects.

Errors & when Claude is down

I got an error message on startup.

See Troubleshooting for the common messages. Screenshot it and ping @Christine Nguyen.

Claude's workspace won't start, or you see a “VM” error.

First, restart Claude — close it fully and reopen; that clears most sandbox hiccups. If it still won't start — or you see a VM error (like “VM service not running” or a cowork-vm message) — restart your whole device (laptop / PC) and wait for Claude to come back up. If that doesn't do it, shut the device all the way down, wait a few minutes, then turn it back on. That usually clears it when Claude’s status is green but the VM/sandbox is down. If Claude itself is down, a reboot won't help — give it 15–30 minutes to recover instead. See Troubleshooting for the exact error messages.

Claude says it can't connect to the Chrome browser.

Two things to check: (1) have a Chrome window already open on your new Claude profile before the browser skill runs, and (2) make sure the Claude Chrome extension is installed and you're logged into it (Step 2). Then tell Claude to try again. See Claude in Chrome.

What should I do while Claude is down?

Hold off on submissions until status is green. Don't reinstall — an outage isn't fixed on your end.
