Org Skill · Create SOV

Fills out the HOA Statement of Values (SOV) on the standard company template, pulling everything it can from whatever source files you provide — expiring / dec pages, a prior SOV, loss runs, broker emails, coverage summaries, SB1525 disclosures, or any mix.

  1. In Cowork (on Sonnet), attach your source files with the + button, type /lo-create-nb-sov, and press the orange arrow or Enter. Attach whatever you have — dec pages, a prior SOV, loss runs, broker emails, and so on.
  2. Claude reads everything and shows you a summary first — it lays out the values it pulled in tidy tables (General Info & Liability, Limits), each with the source it came from, so nothing lands in the SOV until you've seen it.
  3. Answer any check-ins. If a value is missing or a source is unclear, Claude asks you rather than guessing. Anything it can't confirm is left blank and highlighted in yellow in the SOV, so you can fill it in or double-check it yourself later.
  4. Save it where you want it. When it's done, Claude hands you the finished file with a Show in folder button. Click that, then copy the file (Ctrl+C) and paste it (Ctrl+V) into the folder you actually want — or move it there — before opening it.
“File path too long”?Claude saves the SOV to a deep system folder, and Excel sometimes won't open a file from a path that long. If you hit that error, move or copy the file to a normal folder (your Desktop or Downloads) first, then open it from there.
