Scheduled tasks

A scheduled task runs on its own, on a schedule you set — so routine work happens without you starting it.

What it's good for

  • A morning summary of new emails or the day’s renewals.
  • A weekly recap of what’s still outstanding.
  • Any routine check you’d otherwise have to remember.

The Scheduled page also suggests ready-made ones — Daily briefing, Inbox triage, Meeting prep, Weekly review and more. Pick one and adjust it.

Setting one up

Open Scheduled in the sidebar and click New task (top-right).

Create with Claude — describe what you want and answer a few questions. You can also type “I want to make a scheduled task that…” in any Cowork chat, or /schedule in an existing one.

Set up manually — fill in:

  • Name and Instructions (required), plus an optional folder and the model.
  • Frequency and time — e.g. Daily at 7:00 AM.
  • Permissions — choose Automatically approve recommended.
  • Require this computer — leave it off so it runs in the cloud. Only turn it on if the task needs your local folders or Claude in Chrome; it then runs only while your computer is awake (turn on Keep computer awake in Settings → Desktop app → System — closing the laptop lid still puts it to sleep).
Recommended: Automatically approveScheduled tasks run while you’re not watching. On Automatically approve, Claude finishes on its own and only stops if something looks unsafe. On Manually approve, each run waits as Permissions needed until you click Review. See Permissions.

When it runs

It runs at the set time and you get a notification. Runs appear in the Active list on your home screen and under Scheduled. One that’s waiting on you shows Permissions needed with a Review button.

Managing your tasks

Open any task from the Scheduled page.

  • Toggle (by the title) — pause or resume. It shows Active and the next run time.
  • Run now, pencil to edit, bin to delete.
  • History — click a run to see what Claude did. ✋ = it stopped to ask permission; blue dot = a new run you haven’t opened.
Write it like you won't be thereBe specific — e.g. “summarize only today’s new emails” — since you won’t be around to clarify.
