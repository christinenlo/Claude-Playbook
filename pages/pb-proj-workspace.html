The project workspace

Open a project and the right-hand side shows its settings. What you see depends on the project type.

Local project

  • Instructions — how you want Claude to work in this project.
  • Memory — things Claude remembers for the project (marked 🔒 Only you).
  • Context — the folder on your computer that Claude reads as reference — no capacity meter, since the files stay on your PC.
  • Scheduled — set up recurring tasks for the project.

Shared project

  • Instructions and Memory — the same panels, shared with project members.
  • Context — the files and knowledge stored in the project. Because they're uploaded to Claude (not just read off your PC), it shows a “% of project capacity used” meter so you can see how full it is.
  • Activity — a tab next to “Chats and tasks” showing recent project activity.
Local vs. shared ContextA shared project shows a % capacity meter under Context (its files live in the project, which has a size limit). A local project shows no percentage — it just points to a folder on your computer.
