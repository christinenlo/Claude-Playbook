Creating a project

In the left panel, click Projects, then New project (top-right). Your Projects screen has three tabs:

  • Your projects — the ones you created.
  • Organization — projects shared with everyone in your organization.
  • Shared with you — projects someone shared with you directly.

In the Create a project window you can:

  • Name it — “What are you working on?”
  • Describe it — “What are you trying to achieve?” (goals, subject, and so on).
  • Set visibility — your organization (everyone can view and use it) or Private (only invited members).
  • Add a folder (top-right) — this changes the project type; see Folder or no folder below.

Click Create project to finish. Learn more: support.claude.com → What are projects, or watch the Projects walkthrough (YouTube).

Move chats in or out of a projectAny chat or task can be filed into a project — or taken back out — from its … menu (hover it in the left list, or use the ▾ by its title) → Add to project. To pull it back out, open the same menu and remove it from the project. See Renaming & quick actions.
