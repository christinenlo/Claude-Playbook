🔍 Web search & Research

Claude can look things up online and pull from a web page — or do a deeper, multi-source dig.

Web search

Turn on Web search from the + (or sliders) menu in the chat box. With it on, Claude looks things up on the web and every answer comes with clickable citations so you can check the source. You can also paste a link and Claude will read that page to summarize or pull details from it.

On a Team/Enterprise workspace, an owner may need to switch this on first. It uses more of your usage on long pages.

Research (a deeper dig)

For a bigger question that needs several sources, use Research from the + menu (web search must be on). Claude runs a series of linked searches over a couple of minutes and comes back with a written, cited report — good for market or regulatory digging where one search isn’t enough. If it doesn’t kick in, just say “please use the research tool.” Research uses more usage than a normal chat.

Which one?Quick fact or a specific page → Web search. Thorough, many-source answer → Research. Your own accounts and documents → keep those in a project or use the Microsoft connectors.
