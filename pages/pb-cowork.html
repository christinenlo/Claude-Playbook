Using Cowork

How to prompt Claude

You don't need special wording — just be clear about what you want. Three things make the biggest difference:

  1. Be specific. Say what you want, for which account, and in what format. The more context you give, the better the result.
  2. Give an example. Paste a sample, point to a past file, or describe the format you're after — Claude will match it.
  3. Iterate, don't restart. If a draft is close, tell Claude what to change in plain English instead of starting a brand-new chat.
Instead of (vague)Try (specific)
“Fill out the Arden form.”“Run /lo-arden-submission for Sample Ridge HOA using the attached SOV. Show me the values before submitting.”
“Write a letter to the board.”“Draft a board letter explaining the 12% premium increase on the Sample Oaks renewal — under 200 words, professional but warm.”
“Make a comparison sheet.”“Build a comparison sheet for Sample Villas: expiring vs. the two attached renewal options. Highlight the deductible and wind/hail differences.”
Have Claude confirm before it startsFor anything important — a submission or a bulk change — ask Claude to play it back first: “Before you start, summarize what you're going to do,” or “Repeat my request and your plan back to me, then wait for my OK.” If the summary is off, you've caught it before any work happens.
If a result isn't rightDon't start over — just tell Claude what's off: “the year built should be 1998, not 1988,” or “make the tone less formal.” It'll correct from there.

Uploading files

Claude reads files you attach directly — no need to copy-paste their contents. Two ways to add one:

  • Click the + button in the chat box → Add files or photos, then pick your file.
  • Or drag and drop the file straight into the chat.

What you can attach: PDFs, Excel (SOVs, loss runs), Word docs, PowerPoint, .vtt transcripts, and images/screenshots — Claude reads the content and works from it.

TipMost carrier skills expect the SOV (Excel) — the Org Skills Directory lists exactly what each one needs.

Uploading folders

You can also give Claude a whole folder to work in — not just single files. Use the + button in the chat box and choose to add a folder, or drag a folder straight in. Claude can then read everything inside it and save its work there.

Claude only sees what you shareClaude can't touch any file or folder you haven't shared with it — it has no access to the rest of your computer. For example, if you ask Claude to save something to your Downloads folder but you haven't shared Downloads, it will fail. Share the folder first, then ask again.

Sharing a folder once lets Claude reuse it for the whole task — handy when a skill needs to read several files from one place, or drop its output somewhere specific.

Mind the sizeKeep an eye on how big the files and folders you share are. Large ones make Claude slower and use up your usage faster — every file Claude reads costs tokens. Share just what the task needs, not your whole drive.

Finding your files

When Claude creates a file, it shows a Show in folder button that opens the folder it saved to. That path can be buried and awkward to get back to, so here are two easy ways to put the file where you want it:

  • Copy it there yourself. Click Show in folder, then copy the file (Ctrl+C, or right-click → Copy) and paste it (Ctrl+V, or right-click → Paste) into any folder you like. This always works — you're moving it in File Explorer yourself, so it doesn't matter whether Claude has access to that folder.
  • Ask Claude to move it. Once the file pops up, just tell Claude “move it to my Downloads folder” or “save it to my Desktop.” This one only works if that folder is shared with Claude — otherwise the move will fail.

Inside a Cowork task

When a Cowork task is running, the right-hand side shows live panels so you can follow along and step in whenever you want:

  • Progress — the checklist of steps Claude is working through. Finished steps get a checkmark; the current one is highlighted.
  • Working folders — the files and folders Claude is reading from and saving to for this task (for example, your Downloads folder, an instructions file, or a policy PDF).
  • Claude in Chrome — shows up only when the task uses the browser, and tells you which Chrome window it's driving (see Claude in Chrome).
  • Context — tracks the tools and referenced files used in the task.

Claude in Chrome

When a task needs Claude to actually work in the browser — running certain skills, filling a carrier portal, or other browser tasks — it uses Claude in Chrome. Claude only touches the browser when you allow it (see Permissions).

You need the Claude Chrome extensionClaude in Chrome works only if you've installed the Claude extension for Google Chrome — it's the connector between Claude and your browser (set up in Step 2). Heads up: Anthropic's separate “Control Chrome” feature is macOS only, so on Windows the Chrome extension is what makes this work.
Open Chrome firstBefore you run a browser skill, have a Chrome window already open on your new Claude profile. If Claude says it can't connect to the browser, that's usually why — open Chrome on the Claude profile (and check the extension is installed and logged in, from Step 2), then tell Claude to try again.

Each browser-connected skill opens its own Chrome tab, labeled with the task name (e.g. "Epic," "Arden"), so parallel tasks are easy to tell apart. A tab shows an hourglass while Claude works and a checkmark when a step finishes.

Claude works within its Chrome tab groups (the colored labels above), and you decide which tabs it can reach:

  1. Add a tab so Claude can use it — right-click any open tab → Add tab to group, then choose Claude (or New group to start one). That tab is now in Claude's group, so it can work with it too.
  2. Take a tab back out — right-click a tab in the group → Remove from group, and Claude can no longer touch it.
  3. Your group saves itself — Claude's group pins to your bookmarks bar (the “Claude” label), so it's there next time. Use the little arrow to collapse it and tidy your tabs.
  4. Clean up when you're done — right-click the Claude group on the bookmarks bar to Open it, Unpin it from the bar, or Delete group. Delete it after each use or keep it handy for next time — your call.
Fewer interruptionsWhen Claude asks for browser permission, use the dropdown to choose "All for this website" (instead of "Allow for this website") so it can keep working without asking each time.

Pin your chats

Pinned chats sit at the top for fast access.

Right-click a chat → Pin (right-click again to unpin)… or click-and-drag a chat up until "Drop here" appears… then release to drop it under Pinned.

Renaming & quick actions

Give your chats and tasks clear names so they're easy to find later — and reach a handful of other actions from the same menus. There are two places to find them.

Inside an open chat or task

Click the ▾ (down-arrow) next to the title at the top.

That opens a menu with Schedule, Turn into skill, Pin, Rename, Add to project, Archive, and Delete. Pick Rename to type a new name right in the title.

From the list on the left

Hover over any chat in the left sidebar and click the … that appears. You'll get Open as quick task, Pin, Mark as unread, Rename, Add to project, Archive, and Delete.

What they doPin keeps it at the top (see Pin your chats) · Turn into skill saves a task you repeat as a reusable skill · Schedule sets it to run on a repeating basis · Archive hides it without deleting · Delete removes it for good.

Sharing chats & tasks

Chats can be shared. Cowork tasks cannot. If you want a colleague to see a conversation, you can share a chat — but there's no share option for a Cowork task, so those stay yours only.

To share a chat:

  1. Open the chat and click the Share button in the top-right corner.
  2. Choose Shared (anyone in your organization can view), then click Create share link.
  3. Copy the link and send it to whoever needs it.
What actually gets sharedA share is a snapshot — it only includes the messages sent up to the moment you press Share. Anything you say afterward stays private until you share again. Attached files are never shared — only the conversation itself is visible to viewers.

To unshare: open Share again, switch it from Shared back to Keep private, and the old link stops working.
