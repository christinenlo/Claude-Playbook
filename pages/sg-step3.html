3Download Claude Desktop (Windows)

Install link (copy & paste): https://claude.com/download

Or search "claude desktop download" in Google.

  1. Open the link and click Download for Windows.
  2. Run the installer from your downloads. Click Yes when Windows asks to allow changes.
  3. When done, Claude appears in your taskbar. Right-click it → Pin to taskbar.
  4. Open Claude → Get Started → log in with your email → click Next through setup. On the main screen, make sure you're on the Cowork tab (the Chat / Cowork toggle sits inside the chat box).
  5. Set your model: click the model name (bottom-right of the chat) and choose Sonnet for everyday work. Next to it you’ll see an effort level (Low / Medium / High) — Medium is fine.

Seeing an error on startup? See Troubleshooting for the common messages and what to do.
